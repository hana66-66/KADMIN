## 数据来源约定

- **卡名 / 词条 / 效果**：取自卡面文字（OCR）
- **稀有度 / 花费**：以文件名的标注为准，与卡面徽章互相校验
- **兵种**：现有卡库里有同名卡的用卡库权威值；其余按卡名推测（文档里标了「按卡名推测」）
- **油费**：整卡 OCR 里 K 图标会把油费数字挤掉，故把燃油位裁出来放大 10 倍单独识别；读数标了「存疑」的要人工确认
- **攻击 / 血量**：卡面军标数字；个别读不到的用裁剪位专读补齐
