词条图标素材文件夹
==================

放置规则
--------
- 一个词条一张图，**文件名 = 词条中文名**（不含扩展名），支持 .png / .jpg / .jpeg / .webp
- 建议：正方形（如 64×64 或 128×128）、透明底 PNG，画面简洁可辨

需要的文件名（缺哪个就用文字回退，不影响游戏）
------------------------------------------------
词条：
  闪击.png        推进后仍可攻击
  守护.png        地面单位必须优先攻击它
  伏击.png        每回合首次被攻击时先反击
  烟幕.png        无法被攻击；移动或攻击后失去
  奋战.png        一回合可攻击两次

  冲击.png        首次攻击时被攻击单位不反击
  老兵.png        满足条件后升为老兵
  协力.png        无同国友军时总部受 1 点士气伤害
  情报1.png       使用时显示敌方 1 张手牌

状态 / 属性（也会显示在场上单位上）：
  压制.png        被压制：不能移动/攻击（红色高亮显示）
  重甲.png        受到伤害减少（旁边会叠加数值，如 重甲1 → 图标+1）

生效方式
--------
放好图片后执行 `node build.mjs` 重新构建即可（手牌不显示词条，只有场上单位显示）。
