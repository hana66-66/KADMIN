# KADMIN 开发者模式（外挂面板 · 独立 exe）

给 `开发\KADMIN-卡兹铭刻.html` 用的调试/作弊面板：**原生 Windows 小窗口**（不是浏览器页面、不是脚本宿主），
像外挂一样实时改游戏。

## 怎么用

1. 浏览器里打开游戏：`开发\KADMIN-卡兹铭刻.html`（保持开着）
2. 双击 **`启动开发者面板.cmd`**（或直接双击 `KADMIN开发者面板.exe`）→ 弹出小窗口
3. 面板顶部显示「**● 在线**」即可开工（首次连接最多等 4 秒）

> 首次运行如果弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
> 这是自己用系统自带编译器生成的 exe，没有数字签名，属正常提示。

## 功能

| 分类 | 功能 |
|---|---|
| 卡牌 | 搜卡名/id → **加入手牌 / 加入战场 / 置于卡组顶** |
| 卡池范围 | 正常卡池（五国全部单位/指令/反制）· **衍生卡** · **JM（SUPERMAN / SUPERTANK）** · **老兵形态**，共 441 张 |
| 开关 | **无限指挥点**（顶到 99，花掉 1 秒内自动补回）· **我方/敌方总部免疫伤害** |
| 按钮 | **跳过 AI 下个回合** · **双方总部回满** · **直接获胜**（Boss 剩余命数一并跳过） |
| 状态栏 | 回合/阶段、双方血量（含 Boss 第几条命）、指挥点，实时刷新 |
| 日志 | 每条命令的去向 + 游戏的回执（✔/✖） |

- 加入战场：默认进你的**支援战线**（底线最左空位），满了自动上前线
- 置于卡组顶 = 你下一张摸到的就是它
- 指令/反制卡不能进战场（面板会禁用按钮，游戏也会回一句说明）

## 它是怎么连上游戏的

不需要网络、不需要插件、不需要管理员：

```
exe 面板  ── 内置 TcpListener(127.0.0.1:7788，最小 HTTP) ──┐
                                                          │  游戏每 0.5 秒 GET  /poll?since=N  ← 取命令
KADMIN（file:// 页面，src/dev.js 里的开发者桥） ───────────┤  游戏 POST /ack   ← 回执（面板日志里的 ✔）
                                                          └  游戏 POST /index ← 441 张卡表；POST /state ← 局面
```

- 面板没开时：游戏侧只是每 4 秒一次连接失败（退避），正常游戏**零影响**
- 面板后开也行：游戏会自动连上（最多 4 秒）；面板关了游戏照常玩
- 协议就四个路径：`/poll` `/ack` `/index` `/state`（想自己写脚本对接也方便）

## 自己改 / 重新编译

- 源码：`KADMIN开发者面板.cs`（C# 5 语法，兼容系统自带编译器）
- 重新编译：双击 **`重新编译面板.cmd`**（调用 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，无需安装任何东西）
- 命令行参数：`-selftest`（自检：自动排队 6 条命令并写日志到 `%TEMP%\kadmin-dev-panel.log`）、`-port=7788`

## 备用方案（浏览器版）

`备用方案（浏览器版）\` 里是同一套功能的两份兜底实现，万一 exe 被安全软件拦了可以用：

- `KADMIN 开发者模式.html` —— 浏览器页面版面板（走浏览器本地存储通信，**必须与游戏同一个浏览器**）
- `KADMIN 开发者面板.ps1` —— PowerShell 脚本版（同 exe 一样的 HTTP 通信，双击 `.cmd` 启动）
